How the numbers were measured

Rebuilds: nixpkgs was evaluated for x86_64-linux with nix-eval-jobs, covering what nix-env -qa lists. A package's count is how many of those packages have its .drv in their build closure. Each revealed count names a few of them. docs/data.md has the full method.

Closure size: the sum of NarSize over the runtime closure of the package's default output on cache.nixos.org, which is what nix path-info -S prints. The page repeats the walk when a size is revealed, and the size links to the closure on seenix.

Versions and age: from nixpkgs-multiverse, which records every version at each nixos-unstable channel bump since 2012. It has no bumps from October 2013 to September 2016, so a package added then has a three-year window. Two packages are compared only when their windows are six months apart or more. Click a number to see the package's history.

Pools: Common is the packages with the most rebuilds, plus well-known applications. Deep cuts is the next , ranked by rebuilds and then by versions shipped. Pick with 1 and 2 or the arrow keys, and go on with Enter.
